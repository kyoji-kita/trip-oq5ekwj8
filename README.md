# 広島忘年会旅行2026 しおり

https://kyoji-kita.github.io/trip-oq5ekwj8/

## 編集していいところ

**`data/food.json` だけ編集してください。** 保存（commit）すると1〜2分でしおりの「宿・ごはん」タブの「調べたお店」に出ます。

`index.html` は北が Claude Code で作り直しているので、直接は触らないでください（作り直したときに消えます）。しおりの中身を変えたいときは北に言ってください。

## お店の書き方

`shops` の中に `{ }` を1つ足すと1件増えます。

```json
{
  "name": "店の名前（必須）",
  "when": "1日目の昼（宮島） / 1日目の夜 / 2軒目 / 2日目の昼（呉） / おみやげ など",
  "kind": "お好み焼き・牡蠣・カフェ など",
  "area": "場所と、KIROや駅からの距離",
  "budget": "1人いくらくらい",
  "status": "候補 / 決定 / 予約済み / 見送り",
  "note": "おすすめの理由・混み具合・予約できるか など",
  "url": "https:// から始まる Googleマップ や お店のページ",
  "by": "調べた人"
}
```

- 使わない項目は消すか `""` のままで大丈夫です。
- 書き間違えると GitHub Actions の「お店データのチェック」が赤くなって、どこが変か教えてくれます。そのときもしおりは壊れず、前の内容のまま出ます。
- `when` が同じお店はまとまって並びます。
